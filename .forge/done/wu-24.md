# Tag deployment — git layer and deployer ref param

## Outcome
`CloneOrFetch` accepts a `ref` string that can be a branch name (`main`, `dev`) or a full tag refspec (`refs/tags/v1.2.3`). `Deploy` and `DeployAsync` gain a `ref string` parameter — empty means "use whatever the app config says", non-empty overrides it. The deployer resolves the effective ref from `app.Tag` or `app.Branch` and passes it through to git.

## Values
1. Single code path for branches and tags — no parallel logic, no special-casing outside git.go.
2. `FETCH_HEAD` for reset — already in place; works for both branches and tags without change.

## Context
- `internal/git/git.go` — `CloneOrFetch(ctx, token, dir, url, branch string)`. Rename `branch` param to `ref`. Adjust clone and fetch commands as described below.
- `internal/deployer/deployer.go` — `Deploy(ctx, appName string)` and `DeployAsync(appName string)`. Add `ref string` param to both. Add helper `effectiveRef(app) string`.
- `cmd/deploy.go` — calls `d.Deploy(context.Background(), name)` (two places). Update to pass `""` as ref.
- `cmd/serve.go` — calls `d.DeployAsync(req.AppName)`. Update to pass `req.Ref` (added in wu-25; for now pass `""`).

## Requirements

### 1. `CloneOrFetch` — ref param and tag handling

`ref` is either a branch name (`main`) or `refs/tags/v1.2.3`.

```go
func CloneOrFetch(ctx context.Context, token, dir, url, ref string) error {
    _, err := os.Stat(dir)
    if os.IsNotExist(err) {
        // git clone --branch accepts both branch names and tag names (not full refspecs)
        cloneRef := ref
        if strings.HasPrefix(ref, "refs/tags/") {
            cloneRef = strings.TrimPrefix(ref, "refs/tags/")
        }
        cmd := CmdWithAuth(ctx, token, "", "clone",
            "--branch", cloneRef, "--single-branch", "--depth", "1",
            url, dir,
        )
        out, err := cmd.CombinedOutput()
        if err != nil {
            return fmt.Errorf("git clone: %w: %s", err, strings.TrimSpace(string(out)))
        }
        return nil
    }
    if err != nil {
        return fmt.Errorf("stat repo dir: %w", err)
    }

    // git fetch origin <ref> — works for branch names and refs/tags/v1.2.3
    fetchCmd := CmdWithAuth(ctx, token, dir, "fetch", "origin", ref)
    if out, err := fetchCmd.CombinedOutput(); err != nil {
        return fmt.Errorf("git fetch: %w: %s", err, strings.TrimSpace(string(out)))
    }
    // FETCH_HEAD is always set by the preceding fetch
    resetCmd := CmdWithAuth(ctx, token, dir, "reset", "--hard", "FETCH_HEAD")
    if out, err := resetCmd.CombinedOutput(); err != nil {
        return fmt.Errorf("git reset: %w: %s", err, strings.TrimSpace(string(out)))
    }
    return nil
}
```

### 2. Deployer — `effectiveRef` helper

Add a private function that determines the ref to use for git operations:

```go
// effectiveRef returns the git ref to use for a deploy.
// override takes precedence; otherwise app.Tag (as refs/tags/<tag>) or app.Branch.
func effectiveRef(app config.App, override string) string {
    if override != "" {
        return override
    }
    if app.Tag != "" {
        return "refs/tags/" + app.Tag
    }
    return app.Branch
}
```

Update `gitSync` signature:
```go
func (d *Deployer) gitSync(ctx context.Context, appDir string, app config.App, ref string) error {
    repoDir := filepath.Join(appDir, "repo")
    d.Logger.Info("git sync", "repo", app.Repo, "ref", ref)
    return git.CloneOrFetch(ctx, d.Config.Server.GithubToken, repoDir, git.RepoURL(app.Repo), ref)
}
```

Inside `DeployAsync`, propagate `ref` to the `Deploy` call.
