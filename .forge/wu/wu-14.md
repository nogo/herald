# Refactor: deduplicate, remove dead code, and clean up

## Outcome

The codebase has zero duplicated utility functions, no dead code, consistent error handling across all commands, and shared infrastructure extracted into reusable internal packages. `go vet`, `go test`, and `go build` all pass. Functionality is unchanged.

## Values

1. Single source of truth — every utility function exists in exactly one place.
2. Consistency — all commands handle errors, logging, and output the same way.
3. Maintainability — fixing a bug in git auth, compose generation, or command execution fixes it everywhere.

## Context

The codebase grew through 13 work units plus manual patches. Three packages (`deployer`, `preview`, `stacks`) independently implemented the same helpers: git operations, compose override generation, env file writing, secret file writing, caddy network management, and command execution. There are 25+ duplicated functions across these packages.

## Creates

- `internal/runner/runner.go` — shared command execution (`RunCmd`, `RunExecCmd`).
- `internal/compose/compose.go` — shared compose types (`Override`, `ServiceOverride`, `NetworkDef`, `SecretFileDef`) and helpers (`DetectServiceInfo`, `GenerateOverride`, `DeepMerge`, `WriteEnvFile`, `WriteSecret`).
- `internal/git/git_test.go` — tests for the shared git package.

## Modifies

Every change below preserves existing behavior. No API changes to exported types.

### Phase 1: Expand `internal/git` and create `internal/runner`

**`internal/git/git.go`**:
- Add `context.Context` parameter to `CmdWithAuth` → `CmdWithAuth(ctx, token, dir, args...)`.
- Add `CloneOrFetch(ctx, token, dir, url, branch)` that encapsulates the clone-or-fetch+reset pattern used by deployer, preview, and bootstrap.
- Update `PullFFOnly` to accept `ctx`.

**`internal/runner/runner.go`** (new):
- Move `runCmd(ctx, logger, dir, name, args...)` from deployer.
- Move `runExecCmd(ctx, logger, cmd)` from deployer.
- Export as `runner.RunCmd` and `runner.RunExecCmd`.

**`internal/caddy/caddy.go`**:
- Extract `EnsureNetwork` as a standalone exported function `EnsureNetwork(ctx, logger)` (not a method).
- Unexport the method version or delegate to the function.
- Replace local `runCmd` with `runner.RunCmd`.

### Phase 2: Create `internal/compose`

**`internal/compose/compose.go`** (new):
- Move types: `Override`, `ServiceOverride`, `NetworkDef`, `SecretFileDef`.
- Move `DetectServiceInfo(filePath, serviceName, defaultPort)`.
- Move `portFromAny`, `extractFirstPort` (unexported helpers).
- Move `DeepMerge(base, overlay map[string]any)`.
- Move `WriteEnvFile(root *os.Root, envVars map[string]string)`.
- Move `WriteSecret(root *os.Root, name, value string)`.

### Phase 3: Rewrite deployer, preview, stacks to use shared packages

**`internal/deployer/deployer.go`**:
- Delete: `gitCmdWithAuth`, `repoURL`, `runCmd`, `runExecCmd`, `writeEnvFile`, `writeSecret`, `ensureCaddyNetwork`, `deepMerge`, `detectServiceInfo`, `portFromAny`, `extractFirstPort`, and all compose override types.
- Replace calls with `git.CmdWithAuth`, `git.RepoURL`, `git.CloneOrFetch`, `runner.RunCmd`, `compose.WriteEnvFile`, `compose.WriteSecret`, `caddy.EnsureNetwork`, `compose.DeepMerge`, `compose.DetectServiceInfo`.
- File drops from ~510 lines to ~200 lines.

**`internal/preview/manager.go`**:
- Delete same functions as deployer (all duplicates).
- Replace with shared package calls.
- File drops from ~700 lines to ~300 lines.

**`internal/stacks/manager.go`**:
- Delete `ensureCaddyNetwork`, `detectServiceInfo`, `portFromAny`, `extractFirstPort`, compose types.
- Replace with shared package calls.
- Replace local `runCmd` with `runner.RunCmd`. Keep `lineWriter`/`ringBuffer` (streaming specific to stacks).

**`internal/init/bootstrap.go`**:
- Delete `gitCmdWithAuth`, `repoURL`.
- Replace with `git.CmdWithAuth`, `git.RepoURL`, `git.CloneOrFetch`.

### Phase 4: Remove dead code

- `cmd/sync.go`: delete `syncRunCmd` (line 275, never called).
- `internal/github/auth.go`: delete `DefaultClientID` constant (empty, unused).
- `internal/systemd/service.go`: remove `Port` and `GithubToken` fields from `ServiceConfig`. Update test.
- `cmd/serve.go`: replace raw `exec.Command("git", ...)` in `getIaCRepo()` with `git.CmdWithAuth`.

### Phase 5: Fix inconsistencies

- Replace all `os.Exit(1)` inside `RunE` functions with `return fmt.Errorf(...)`:
  - `cmd/install.go:25,45`
  - `cmd/uninstall.go:16`
  - `cmd/deploy.go:75`
  - `cmd/secret.go:86,144`
  - `cmd/update.go:53`
- Add `cmd.SilenceUsage = true` to all remaining commands: caddy, webhooks, preview subcommands.
- Fix `caddy start --herald-port` default from 8080 to 9483.
- Replace `fmt.Printf`/`fmt.Println` in `internal/caddy/caddy.go` with logger calls.

## Constraints

- `go build ./...` must pass.
- `go vet ./...` must pass.
- `go test ./...` must pass — all existing tests continue to work.
- No behavioral changes — same inputs produce same outputs.
- No new dependencies.
- Exported API surface of `deployer`, `preview`, `stacks` packages must not change (struct types and their public methods stay the same).
