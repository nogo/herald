# Fix inconsistencies and remove dead code

## Outcome

All commands handle errors consistently (no `os.Exit` inside `RunE`), all subcommands set `SilenceUsage`, port defaults are consistent, dead code is removed, and logging follows a single pattern. `go vet`, `go test`, and `go build` all pass.

## Values

1. Consistency — every command follows the same error handling and output pattern.
2. Correctness — no dead code that misleads readers or hides bugs.
3. Predictability — port defaults are the same everywhere (9483).

## Context

- This WU runs after wu-14 (deduplication). Wu-14 extracts shared packages and removes duplicate functions. This WU cleans up the remaining inconsistencies that wu-14 does not address.
- The codebase uses Cobra for CLI commands. Cobra's `RunE` should return errors, not call `os.Exit`. When `RunE` returns an error, Cobra prints it and exits with code 1. Calling `os.Exit` directly skips deferred cleanup and bypasses Cobra's error formatting.
- `cmd.SilenceUsage = true` prevents Cobra from printing the usage/help text on runtime errors. Without it, a failed deploy prints the full usage message, which is confusing.

## Modifies

### 1. Replace `os.Exit(1)` with `return fmt.Errorf(...)` in RunE functions

**`cmd/install.go`** — two places:
- Root check: `os.Exit(1)` after printing "must be root" → `return fmt.Errorf("installing systemd service requires root. Run: sudo herald install")`
- Missing user: `os.Exit(1)` after printing user doesn't exist → `return fmt.Errorf("user '%s' does not exist. Create it first: sudo useradd -r -m -d /home/%s -s /bin/bash -G docker %s", installUser, installUser, installUser)`

**`cmd/uninstall.go`**:
- Root check: same pattern → `return fmt.Errorf(...)`

**`cmd/deploy.go`**:
- Deploy failure: `os.Exit(1)` after printing error → already returns error from `RunE`, remove the `os.Exit(1)`. Check if there's a redundant exit after an error print.

**`cmd/secret.go`**:
- `secretGetCmd`: `os.Exit(1)` when key not found → `return fmt.Errorf("secret '%s' not found", key)`
- `secretDeleteCmd`: `os.Exit(1)` when key not found → `return fmt.Errorf("secret '%s' not found", key)`

**`cmd/update.go`**:
- `os.Exit(1)` after update failure → `return fmt.Errorf(...)`

### 2. Add `cmd.SilenceUsage = true` to all subcommands missing it

Add to the start of every `RunE` function that doesn't have it:
- `cmd/caddy.go`: `caddyStartCmd`, `caddyStopCmd`, `caddyStatusCmd`
- `cmd/webhooks.go`: `webhooksSyncCmd`, `webhooksListCmd`
- `cmd/preview.go`: `previewListCmd`, `previewRemoveCmd`, `previewCleanupCmd`

### 3. Fix port default mismatch

**`cmd/caddy.go`**: The `caddyStartCmd` has a `--herald-port` flag defaulting to `8080`. Change to `9483`.

Verify that `cmd/sync.go` and `cmd/status.go` use `Cfg.Server.Port` (from config, which defaults to 9483 in the loader) rather than the `port` variable from `serve.go`.

### 4. Remove dead code

**`cmd/sync.go`**: Delete the `syncRunCmd` function if it still exists after wu-14. It was identified as never called.

**`internal/github/auth.go`**: Delete `const DefaultClientID = ""` — empty string, never used.

**`internal/systemd/service.go`**: Remove `Port int` and `GithubToken string` fields from `ServiceConfig` struct. These fields exist but are never read by the template or any code. Update `cmd/install.go` to not set them. Update `internal/systemd/service_test.go`:
- `TestGenerateUnitFile_noTokenInUnitFile`: remove `GithubToken` field from test config. Rename test to `TestGenerateUnitFile_security` or similar. Keep the assertion that no token appears in the unit file (now trivially true since the field is gone). Keep the assertion that `EnvironmentFile` is present.

### 5. Fix internal logging inconsistency

**`internal/caddy/caddy.go`**: Replace `fmt.Printf(...)` and `fmt.Println(...)` calls with `slog.Info(...)` or pass output through the logger:
- Line with `fmt.Printf("caddy started on :80/:443, ACME email: %s\n", ...)` → `m.Logger.Info("caddy started", "ports", ":80/:443", "acme_email", ...)`
- Line with `fmt.Println("caddy stopped")` → `m.Logger.Info("caddy stopped")`

### 6. Fix `getIaCRepo` in cmd/serve.go

Replace the raw `exec.Command("git", "-C", repoDir, "remote", "get-url", "origin")` with `git.CmdWithAuth(context.Background(), "", repoDir, "remote", "get-url", "origin")` for consistency (hooks disabled). No auth needed for this local-only command, but pass empty token.

Similarly, fix `internal/status/collector.go` `readGitHead` to use `git.CmdWithAuth(ctx, "", repoDir, "rev-parse", "--short", "HEAD")`.

## Constraints

- `go build ./...` must pass.
- `go vet ./...` must pass.
- `go test ./...` must pass.
- No behavioral changes — same inputs produce same outputs.
- Do not change exported API surfaces.
- This WU assumes wu-14 has already been applied. If `syncRunCmd` or `DefaultClientID` were already removed by wu-14, skip those steps.
