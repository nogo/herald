# Tag deployment — webhook tag push handling

## Outcome
The webhook server handles GitHub push events on tag refs (`refs/tags/v1.2.3`). For each app with a matching `tag_pattern`, it dispatches a deploy with that specific tag ref. Apps with a static `tag:` config do not participate in webhook auto-deploy (they are deployed manually). `DeployRequest` carries the `Ref` field so the deployer receives the exact ref to check out.

## Values
1. Tag pattern matching uses `path.Match` — same glob syntax as the config validation in wu-23.
2. Pinned apps (`tag:`) are never auto-triggered — explicit deploys only.

## Context
- `internal/webhook/server.go` — `handleWebhook`, `DeployRequest`, match loop.
- `cmd/serve.go` — `OnDeploy` callback passes `req.AppName` to `d.DeployAsync`. After wu-24, signature is `DeployAsync(appName, ref string)`.
- Current push handling strips `refs/heads/` prefix and matches on branch name. Tag events arrive with `ref: refs/tags/v1.2.3` — after stripping `refs/heads/` the result is `refs/tags/v1.2.3` unchanged, so the current branch match loop never fires for tags.

## Creates
None.

## Requirements

### 1. Add `Ref` to `DeployRequest`

```go
type DeployRequest struct {
    AppName  string
    App      config.App
    Repo     string
    Branch   string     // branch name for branch push; empty for tag push
    Tag      string     // tag name (without refs/tags/ prefix) for tag push; empty for branch push
    Ref      string     // full ref to deploy: branch name or "refs/tags/v1.2.3"
    Commit   string
    CloneURL string
}
```

### 2. Parse tag vs branch in `handleWebhook`

In the `"push"` case, after extracting `p.Ref`:

```go
case "push":
    var p PushPayload
    if err := json.Unmarshal(body, &p); err != nil { ... }
    repo = p.Repository.FullName
    commit = p.After
    cloneURL = p.Repository.CloneURL
    isDelete = p.Deleted || strings.HasPrefix(p.After, "000000")

    if strings.HasPrefix(p.Ref, "refs/tags/") {
        tagName := strings.TrimPrefix(p.Ref, "refs/tags/")
        // tag push — handled separately below, not via branch match
        if !isDelete {
            s.handleTagPush(repo, tagName, commit, cloneURL)
        }
        writeJSON(w, http.StatusOK, map[string]string{"message": "tag push handled"})
        return
    }
    branch = strings.TrimPrefix(p.Ref, "refs/heads/")
```

Note: tag deletions are ignored (no teardown needed — the running container continues).

### 3. Add `handleTagPush` method

```go
// handleTagPush matches a tag name against each app's tag_pattern and dispatches deploys.
func (s *Server) handleTagPush(repo, tag, commit, cloneURL string) {
    var matched []string
    for name, app := range s.Config.Apps {
        if app.Repo != repo || app.TagPattern == "" {
            continue
        }
        ok, err := path.Match(app.TagPattern, tag)
        if err != nil || !ok {
            continue
        }
        matched = append(matched, name)
    }
    if len(matched) == 0 {
        slog.Info("webhook", "event", "push", "tag", tag, "result", "ignored: no matching tag_pattern")
        return
    }
    slices.Sort(matched)
    slog.Info("webhook", "event", "push", "tag", tag,
        "result", fmt.Sprintf("accepted: %s", strings.Join(matched, ",")))
    for _, name := range matched {
        app := s.Config.Apps[name]
        req := DeployRequest{
            AppName:  name,
            App:      app,
            Repo:     repo,
            Tag:      tag,
            Ref:      "refs/tags/" + tag,
            Commit:   commit,
            CloneURL: cloneURL,
        }
        go s.OnDeploy(req)
    }
}
```

Add `"path"` to imports.

### 4. Populate `Ref` on branch `DeployRequest`

In the existing branch match loop, set `Ref` to the branch name (empty string would also work since deployer defaults to `app.Branch`, but explicit is cleaner):

```go
req := DeployRequest{
    AppName:  name,
    App:      app,
    Repo:     repo,
    Branch:   branch,
    Ref:      branch,
    Commit:   commit,
    CloneURL: cloneURL,
}
```

### 5. `cmd/serve.go` — pass `req.Ref` to `DeployAsync`

Change the `OnDeploy` callback (currently `d.DeployAsync(req.AppName, "")`):

```go
OnDeploy: func(req webhook.DeployRequest) {
    d.DeployAsync(req.AppName, req.Ref)
},
```
