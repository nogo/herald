# Tag deployment — deployed ref in status

## Outcome
After each deploy, herald writes a small state file (`deployed_ref`) to the app deploy directory recording what ref was deployed. `herald status` reads this file and shows it in `AppStatus` — `branch@abc1234` for branch deploys, `tag:v1.2.3@abc1234` for tag deploys.

## Values
1. Single file, single string — no JSON, no schema versioning.
2. Status is informational — a missing file is not an error, just shows `?` for the ref.

## Context
- `internal/deployer/deployer.go` — `Deploy` already has `appDir`, `appRoot`, and the effective ref at hand. Write the file after the compose step succeeds.
- `internal/status/collector.go` — `collectAppStatus` reads `AppStatus.Branch` from config. Replace with reading the `deployed_ref` file. `AppStatus.Branch` becomes `DeployedRef string`.
- The `deployed_ref` file format: a single line `<ref>@<commit>` e.g. `main@abc1234` or `refs/tags/v1.2.3@abc1234`. Display logic can simplify `refs/tags/v1.2.3` → `tag:v1.2.3`.
- `cmd/status.go` — reads `AppStatus.Branch` for display. Update field name/display.

## Creates
None.

## Modifies
internal/deployer/deployer.go
internal/status/collector.go
cmd/status.go

## Requirements

### 1. Write `deployed_ref` in deployer

At the end of `Deploy`, after `runCompose` succeeds, write the deployed ref to `<appDir>/deployed_ref`:

```go
// Write deployed ref for status reporting.
ref := effectiveRef(app, overrideRef)  // overrideRef is the ref param passed to Deploy
if commit, err := readDeployedCommit(filepath.Join(appDir, "repo")); err == nil {
    content := ref + "@" + commit
    _ = os.WriteFile(filepath.Join(appDir, "deployed_ref"), []byte(content), 0644)
}
```

Add a private helper `readDeployedCommit(repoDir string) (string, error)` that runs `git rev-parse --short HEAD` in the given directory using `git.CmdWithAuth(ctx, "", repoDir, "rev-parse", "--short", "HEAD")`. Use a short timeout context (5s) to avoid blocking.

Note: the file write uses `_` for the error — failing to record status must never fail a deploy.

### 2. Update `AppStatus`

In `internal/status/collector.go`, replace `Branch string` with `DeployedRef string`:

```go
type AppStatus struct {
    Name            string `json:"name"`
    Domain          string `json:"domain"`
    DeployedRef     string `json:"deployed_ref,omitzero"`
    State           string `json:"state"`
    ContainersUp    int    `json:"containers_up,omitzero"`
    ContainersTotal int    `json:"containers_total,omitzero"`
    LastCommit      string `json:"last_commit,omitzero"`
}
```

### 3. Read `deployed_ref` in `collectAppStatus`

Replace the `Branch: app.Branch` assignment. After confirming `appDir` exists, read the file:

```go
if data, err := os.ReadFile(filepath.Join(appDir, "deployed_ref")); err == nil {
    s.DeployedRef = strings.TrimSpace(string(data))
}
```

Remove the import/use of `app.Branch` from this function (the config branch is no longer shown in status — the deployed ref is authoritative).

### 4. Display in `cmd/status.go`

Find where `AppStatus.Branch` is displayed (typically a table column header "Branch" and value `a.Branch`). Update:
- Column header: `"Ref"` (or `"Deployed"`)
- Value: format `DeployedRef` for readability: if it starts with `refs/tags/`, show `tag:v1.2.3@abc1234`; otherwise show as-is (e.g. `main@abc1234`). If empty, show `-`.

```go
ref := a.DeployedRef
if strings.HasPrefix(ref, "refs/tags/") {
    ref = "tag:" + strings.TrimPrefix(ref, "refs/tags/")
}
if ref == "" {
    ref = "-"
}
```

## Constraints
- `go build ./...` must pass.
- `go test ./...` must pass.
- A missing `deployed_ref` file must not cause `herald status` to error — display `-`.
- Writing the file must not be in the error path — use `_` for the write error.
- Apps not yet deployed (`appDir` absent) continue to show `state: not deployed`.

## Verification
```bash
go build ./...
go test ./...
```
Manual: `herald deploy <app>` then `herald status` — shows `main@abc1234`. Deploy with a tag; shows `tag:v1.2.3@abc1234`.
