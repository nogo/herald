# `herald down` — stop and remove app containers

## Outcome
`herald down <app>` runs `docker compose down` for the named app, stopping and removing its containers. A `--volumes` flag removes named volumes (destructive, opt-in). The deploy directory (`repo/`, `.env`, `secrets/`) is left intact so `herald deploy` can bring the app back up immediately.

## Values
1. Symmetric with `herald deploy` — same compose files, same project name, inverse operation.
2. Non-destructive by default — volumes survive unless `--volumes` is passed explicitly.

## Context
- `internal/deployer/deployer.go` — add `Down(ctx, appName string, removeVolumes bool) error`.
- `cmd/deploy.go` exists; create `cmd/down.go` as a new file following the same pattern.
- The compose invocation mirrors `runCompose` but calls `down` instead of `up`. The compose file and override file paths are derived the same way.
- The override file may not exist (app was never deployed). If it is absent, omit the `-f overrideFile` flag rather than erroring.

## Creates
cmd/down.go

## Modifies
internal/deployer/deployer.go

## Requirements

### 1. `Deployer.Down`

Add to `internal/deployer/deployer.go`:

```go
// Down stops and removes the containers for the named app.
// If removeVolumes is true, named volumes are also removed.
func (d *Deployer) Down(ctx context.Context, appName string, removeVolumes bool) error {
    app, ok := d.Config.Apps[appName]
    if !ok {
        return fmt.Errorf("app %q not found in config", appName)
    }

    appDir := filepath.Join(d.Config.Server.ServicesDir, "apps", appName)
    repoDir := filepath.Join(appDir, "repo")
    composeFile := resolveComposePath(app.Compose, repoDir)
    overrideFile := filepath.Join(appDir, "compose.override.yml")

    args := []string{
        "compose",
        "--project-name", "herald-" + appName,
        "--progress", "plain",
        "-f", composeFile,
    }
    if _, err := os.Stat(overrideFile); err == nil {
        args = append(args, "-f", overrideFile)
    }
    args = append(args, "down", "--remove-orphans")
    if removeVolumes {
        args = append(args, "--volumes")
    }

    d.Logger.Info("compose down", "app", appName, "remove_volumes", removeVolumes)
    return runner.RunCmd(ctx, d.Logger, repoDir, "docker", args...)
}
```

### 2. `cmd/down.go`

```go
package cmd

import (
    "context"
    "fmt"
    "log/slog"

    "github.com/nogo/herald/internal/deployer"
    "github.com/nogo/herald/internal/secrets"
    "github.com/spf13/cobra"
)

var downVolumes bool

var downCmd = &cobra.Command{
    Use:   "down <app>",
    Short: "Stop and remove an app's containers",
    Long: `Stop and remove the containers for an app.

The deploy directory (repo, .env, secrets) is preserved.
Run 'herald deploy <app>' to bring it back up.

Use --volumes to also remove named Docker volumes (databases, uploads).
This is irreversible without a backup.`,
    Args: cobra.ExactArgs(1),
    RunE: func(cmd *cobra.Command, args []string) error {
        cmd.SilenceUsage = true
        appName := args[0]
        if _, ok := Cfg.Apps[appName]; !ok {
            return fmt.Errorf("app %q not found in config", appName)
        }

        d := &deployer.Deployer{
            Config:  Cfg,
            Secrets: secrets.NewStore(dataDir),
            Logger:  slog.Default(),
            DataDir: dataDir,
        }

        if err := d.Down(context.Background(), appName, downVolumes); err != nil {
            return fmt.Errorf("down %s: %w", appName, err)
        }

        fmt.Printf("down %s: containers stopped\n", appName)
        return nil
    },
}

func init() {
    rootCmd.AddCommand(downCmd)
    downCmd.Flags().BoolVar(&downVolumes, "volumes", false, "Also remove named volumes (irreversible without a backup)")
}
```

## Constraints
- `go build ./...` must pass.
- If the app has never been deployed (no `repo/` dir), the command must still attempt `compose down` — it will be a no-op.
- If `compose.override.yml` is absent, do not pass `-f overrideFile` (avoids a Docker Compose error).
- `--volumes` must not be the default — it must be explicitly passed.

## Verification
```bash
go build ./...
go test ./...
```
Manual:
- `herald deploy <app>` then `herald down <app>` — containers gone, `docker ps` shows nothing for project `herald-<app>`.
- `herald deploy <app>` again — comes back up.
- `herald down <app> --volumes` — named volumes removed.
