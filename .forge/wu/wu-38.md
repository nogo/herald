# Delete internal/services and remove compat shims

## Outcome

The `internal/services/` package is deleted. The deprecated type aliases (`App = Stack`, `Service = Stack`) and computed fields (`Config.Apps`, `Config.Services`) added in wu-28 are removed from `config.go`. No Go source file references `ServiceManager`, `ServiceInfo`, `config.App`, `config.Service`, `Config.Apps`, or `Config.Services`. The codebase compiles and all tests pass.

## Values

1. Clean deletion — no dead code, no unused imports, no deprecated shims.
2. Verify completeness — grep confirms zero references remain.

## Context

- `internal/services/manager.go` — the entire package. All logic absorbed by `deployer` (wu-30, wu-31).
- `internal/services/manager_test.go` — tests for the deleted package.
- `internal/config/config.go` — deprecated type aliases `App = Stack` and `Service = Stack`, computed fields `Apps` and `Services` on `Config` struct, population logic in `Load()`. All removed.
- Any file that still imports `github.com/nogo/herald/internal/services` or references `config.App`/`config.Service`/`Config.Apps`/`Config.Services`.

## Creates

None.

## Modifies

internal/config/config.go
internal/config/config_test.go

(Plus deletion of internal/services/ directory.)

## Requirements

### 1. Delete the services package

Remove `internal/services/manager.go`, `internal/services/manager_test.go`, and any other files in `internal/services/`.

### 2. Remove type aliases from config.go

Delete:
```go
type App = Stack
type Service = Stack
```

### 3. Remove computed fields from Config struct

Remove `Apps` and `Services` fields from the `Config` struct. Remove the population logic from `Load()`.

### 4. Remove stale imports and references

Grep all `.go` files for:
- `"github.com/nogo/herald/internal/services"` — remove import and any code referencing it.
- `config.App` or `config.Service` — replace with `config.Stack`.
- `Config.Apps` or `Config.Services` — replace with `Config.Stacks` (these should already be migrated by wu-33/34/35/37, but verify).
- `ServiceManager`, `ServiceInfo` — remove any remaining references.

### 5. Update config tests

Remove any tests that reference `Apps` or `Services` computed fields.

### 6. Verify

The project must compile with `go build ./...` and all tests pass.

## Constraints

- `mise run check` must pass.
- Do not modify logic — only delete dead code, remove shims, and fix type references.
- If any file still depends on `config.App`/`config.Service` types or `Config.Apps`/`Config.Services` fields that weren't migrated by prior WUs, fix the reference inline to use `config.Stack`/`Config.Stacks`.

## Failure Modes

- **Missing migration**: A code path still uses `Config.Apps` that wasn't migrated by wu-33/34/35/37. Detection: compile error after removing the field. Resolution: fix inline.
- **Test references deleted types**: A test fixture uses `config.App`. Detection: compile error. Resolution: change to `config.Stack`.
