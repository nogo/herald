Your repo. Your server. Herald in between.

Herald turns one server into a git-driven Docker Compose host: a VPS, a Raspberry Pi, the box under your desk. You push. Herald carries the word to it and makes it live.

What a push does

The terminal below shows one push: you add a stack to config.yml and push, nothing else. An editor adds a wiki stack to config.yml. The shell commits and pushes the server repo. On the server, the Herald log shows the webhook arrive, a generated secret, and docker compose up. Finally curl gets HTTP 200 from https://wiki.example.com.

~/my-server/config.yml
laptop: ~/my-server
srv1: journalctl -u herald -f -o cat
  1. 0:edit
  2. 1:push
  3. 2:webhook
  4. 3:deploy
  5. 4:live

Features

push to deploy
A push to an app repo deploys its stack. Tags that match tag_pattern deploy too.
server repo wiring
A push to the server repo reloads config, keeps webhooks in sync and redeploys the stacks that changed.
secrets management
Secrets are age-encrypted on the server and never stored in git. Set one with herald secret set. Herald delivers it as an env var or a Docker secret.
generated secrets
Write generate: alphanumeric, base64 or hex. Herald creates the value on first deploy and keeps it stable after that. Nobody has to invent or see a password.
automatic TLS
Caddy gets a certificate for every domain in the config. Adding a domain is one line.
preview environments
A branch gets its own subdomain. Merging or closing the pull request tears it down.
same repo, many deploys
Deploy one repo several times under different names, branches, tags or domains.
public status page
Opted-in stacks show up, degraded or down, with 90 days of history. Nothing else is public.
herald doctor
Diagnoses deploy and wiring problems and prints the command that fixes them.
works without GitHub
The server repo can be a bare repo on the box. Your git push over SSH is the deploy.

Install

as root, on a fresh server with Docker

curl -fsSL https://raw.githubusercontent.com/nogo/herald/main/scripts/install.sh | sh
sudo -iu herald herald init myorg/my-server
sudo systemctl enable --now herald

no GitHub? herald init with no argument; git push over SSH deploys
